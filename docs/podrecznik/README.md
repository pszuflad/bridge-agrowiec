## Zalecana ścieżka nauki

1. Rozdział **0** (nawigacja) — raz, uważnie.
2. **Pulpit → Staging → Katalog** — codzienny trzon pracy.
3. **Narzuty, Atrybuty, Alerty** — gdy już rozumiesz Katalog.
4. Reszta według potrzeb; **Konfigurację** i **Selly** dopiero po ćwiczeniach na środowisku testowym.

## Uwaga o dokładności

Podręcznik opisuje to, co robią przyciski w kodzie panelu (stan na 2026-10-16). Układ wizualny (np. czy coś jest po lewej,
czy poniżej) zależy od szerokości okna. Jeśli coś w rzeczywistości wygląda inaczej niż w opisie — zgłoś to, a poprawimy
rozdział.
