# Wpis 272 — zamówienia symulacyjne partnerów

`zalozZamowieniaSymulacyjne(db)` zapisuje dwa zamówienia z pełnym adresem dostawy: Adtyres (DOCUMENTORDER, `STREET/ZIP/CITY/COUNTRY=FR`) i TyreWorld (`bestellung`, `lieferadresse` DE), na czterech aktywnych produktach z jednoznacznym powiązaniem Selly. Krok `2026-10-14-partnerzy-symulacja-zamowien` (produkcja).
