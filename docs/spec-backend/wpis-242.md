# Wpis 242 — dane do faktury partnera

Kolumny `partnerzy.faktura_nazwa|nip|ulica|kod|miasto|kraj` (migracja 031), wszystkie opcjonalne (null = nie ustawione); kraj dwuliterowy wielkimi literami. Edycja przez PUT /api/partnerzy/:id (te same pola camelCase). Użycie: zamawiający w zamówieniu Selly (ticket 243).
