# Wpis 262 — kurs partnera: niższy z NBP i ręcznego

`kursEur` (`partnerzy/kurs-nbp.ts`) łączy NBP i kurs ręczny kraju: obowiązuje niższy (remis → ręczny); bez kursu ręcznego sam NBP; NBP niedostępny → porównanie z ostatnim zapisanym, a bez niego sam ręczny z ostrzeżeniem. `kursZrodlo` ignorowane przy wyborze. Szczegóły: `docs/tickets/262-FEATURE-partnerzy-kurs-nizszy-z-nbp-i-recznego/plan.md`.
