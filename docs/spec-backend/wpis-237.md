# Wpis 237 — konfiguracja startowa partnerów (krok wdrożenia)

Krok `2026-10-12-partnerzy-konfiguracja-startowa` (raz na bazę). Uzupełnia tylko puste: nazwę pliku, magazyny (katalog bez MO6/MO7/MO8, stan z dnia wdrożenia — nowe magazyny dodaje się w panelu), kraje (narzut 0 %, przesyłka stała 15 EUR — wartość przyjęta, do poprawienia w panelu), kolumny, aktywność.
Nic nie jest publikowane, dopóki narzut kraju = 0 %. Źródło `MfrCode` z pliku TyreWorld nieznane — kolumna pominięta (do decyzji).
