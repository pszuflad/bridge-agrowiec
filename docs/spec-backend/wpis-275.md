# Wpis 275 — narzut partnera jest całą marżą od ceny zakupu

Od ticketu 275 cena partnera = `zakup × (1 + narzut) / kurs + przesyłka + koszty dodatkowe`, gdzie `narzut` to `partner_kraje.narzut_proc` albo pasująca reguła (`partner_narzuty.wartosc`) — **cała** marża, liczona od ceny zakupu (`products.cena_zakupu`). Marża sklepu z katalogu (`products.marza_pct`) nie wchodzi do wyceny (usunięte `marzaSklepuProc` z `PozycjaEksportu` i z `symulacja-ceny`). Dozwolone: narzut 0 % (cena po koszcie) i ujemny (> -100 %, ≤ 1000 %); dawna blokada „narzut 0 % = ceny nie są publikowane” zniknęła. `PUT /api/partnerzy/:id/kraje/:kraj` wymaga jawnego `narzutProc` (brak pola nie może po cichu znaczyć 0 %). Odpowiedź `symulacja-ceny`: zamiast `marzaSklepuProc`/`doplataProc`/`zrodloDoplaty`/`narzutLacznyProc` jest `narzutProc` i `zrodloNarzutu`. Krok wdrożenia `2026-10-15-partnerzy-narzut-cala-marza` jednorazowo dolicza 6 pkt proc. (dawna marża sklepu) do narzutów krajów i reguł większych od 0.
