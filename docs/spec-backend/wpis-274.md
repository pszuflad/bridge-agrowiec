# Wpis 274 — przesyłka partnerów: reguła palety Erwina

Waga gabarytowa w cenniku partnerów (`partnerzy/transport.ts`) liczy się z kolumn `dlugosc`, `szerokoscPaczki`, `wysokosc` produktu, ale po regule palety Erwina Wojtysiaka (21.06.2023; stary system partnerów): szerokość ≤55 cm → 60, ≤80 cm → 80, powyżej — rzeczywista; wysokość +10 cm (`PALETA`, `wymiaryZPaleta`). Wzór: `dł × szer(z paletą) × wys(z paletą) [m³] × współczynnik kraju`; waga rozliczeniowa = max(rzeczywista, gabarytowa); stawka = pierwszy próg ≥ waga. Limity maks. wymiarów (`maks*`) nadal na wymiarach fizycznych. `KosztPrzesylki`, podgląd GEIS i `symulacja-ceny` zwracają `szerokoscZPaleta`/`wysokoscZPaleta` (`wymiaryZPaleta` w symulacji). Zmiana podnosi przesyłkę dla lekkich i średnich opon (przeskok progu) — patrz `docs/tickets/274-…/raport.md`.
