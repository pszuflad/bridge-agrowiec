# 246 — PARTNERZY: podgląd kosztu przesyłki

Prośba użytkowniczki 2026-10-13. W karcie „Tabele transportowe GEIS” formularz: partner, kraj, waga i wymiary paczki → rozbicie kosztu (waga rozliczeniowa = max(rzeczywista, gabarytowa), próg i stawka GEIS albo stała baza kraju, paliwo %, myto, pakowanie, razem EUR). API: POST /api/partnerzy/geis/podglad-kosztu (to samo liczenie co kalkulator). Tylko odczyt.
