# 243 — PARTNERZY: składniki kosztu przesyłki edytowane per kraj

Uwagi użytkowniczki z panelu (2026-10-12): edycja opłaty paliwowej i drogowej, koszty pakowania, przycisk „Dodaj kraj" żółty. Zakres: migracja 032 (partner_kraje.myto_eur, pakowanie_eur), koszt przesyłki ze stałej bazy kraju = baza × (1 + paliwo %) + myto + pakowanie (paliwo z paliwo_historia: zapis „od dziś", bez przeliczania wstecz), pola Paliwo %/Myto/Pakowanie w tabeli krajów, „Dodaj kraj" wariantem głównym (żółty). Domyślnie składniki 0 = dotychczasowa cena (sama baza).
Poza zakresem: widoczność listy magazynów (czeka na zrzut), „edycja cennika" per kraj — niejednoznaczne, do wyjaśnienia.
